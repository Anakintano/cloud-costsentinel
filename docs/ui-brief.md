# CostSentinel UI brief

**Self-authored under explicit creative delegation.** The user answered Q1 ("something minimalist, no hyping, like a normal black background"),
Q2 ("do what you feel is best"), Q4 ("Professional") and chose "Quiet intro + live console". Q5 to Q8 were delegated. Not interviewed beyond that.

## Constraints from the user (verbatim intent)
Minimalist. Normal black background. No hype. Professional. Intro is short and restrained; the product is the live console.

## Deviation from the scroll-craft skill (stated, deliberate)
The skill's 63 KB engine and device kit are built for cinematic multi-act sites. This page has one pinned scrub act, one reveal and one text act
before a working console, so it uses a ~30 line scroll driver in the page instead of the engine. No generated assets (no kie.ai spend): every pixel
of the intro is the user's real data drawn as SVG. Fingerprint registry: not used (single build).

## Journey (3 beats, then the tool)
1. **Recognition**: your daily spend is noisy. (the line draws as you scroll)
2. **Turn**: a forecast tells you what to expect, and a control band says how far is too far. (band wipes in)
3. **Substance**: the day that breaks the band is caught, and an agent explains it with numbers it fetched itself. (text assembles line by line)
4. **Commitment**: the console. Upload, inspect, ask.

## Feeling curve and peak
| Act | Feeling | Caused by |
|---|---|---|
| Spend line | calm recognition | real data line drawing slowly, no decoration |
| Band | quiet confidence | band wipes across the line, nothing else moves |
| Catch (**peak**) | a small jolt | the one accent colour appears, only on the day that broke the limit |
| Agent text | trust | lines assemble with the exact tool values, then the console |

Peak sentence: "It's the site where one orange mark shows you the exact day your cloud bill went wrong."
Authored silence: between beats 1 and 2 the page holds the line still for ~20% of the scroll.

## Signature move
The accent colour exists only for things that broke a control limit (alert spans, the catch marker, severity badges). Everything else is greyscale.

## Rules kept
No scroll cue, no counters, no em dash, real text (selectable), transform/opacity only, reduced-motion shows the final state, charts have a hover
crosshair, a table view, and labels (colour is never the only signal).
